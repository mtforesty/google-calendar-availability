# weekly-review

毎朝のブリーフが「人間の代わりに気づく」係なら、これは「人間を育てる」係。

## 手順
1. 先に `.claude/skills/daily-brief/NOTION.md` を読み、そのルールに従う(公開リポジトリには何も保存しない)。
2. 取扱説明書と、私が直近7日に編集したページを重点的に読む。今週の「brief」ページも読む。比較用に、関係する古いページも集める。
3. 次の4つを書く:
   - **EMERGING THESIS**: まだ明言していないが、向かいつつある考えや立場は何か
   - **CONTRADICTIONS**: 最近のメモのうち、以前の考えと矛盾するもの。両側を自分のメモから引用し、元ページにリンクする
   - **KNOWLEDGE GAPS**: 読んでいるもの・考えていることから見て、明らかに読めていない視点は何か
   - **ONE ACTION**: 全体を踏まえて、今週いちばん効く一手を1つ
4. 遠慮しない。持ち主に挑む。既に知っていることの要約はしない。
5. 「第二の脳 ブリーフ」の子ページとして「weekly YYYY-MM-DD」を作る。
6. 最後に「取扱説明書の『今読んで考えていること』を更新しよう」と一言添え、更新案を1〜3行で示す(勝手には書き換えない)。コミットはしない。
