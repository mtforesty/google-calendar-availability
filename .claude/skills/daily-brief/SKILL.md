# daily-brief

話しかけてこない第二の脳は、第二の脳じゃない。毎朝、頼まれる前に Notion のメモから1本届ける。

## 手順
1. 先に `.claude/skills/daily-brief/NOTION.md` を読み、そのルールに従う(公開リポジトリには何も保存しない)。
2. 取扱説明書を読み、持ち主の目標・プロジェクト・関心を把握する。
3. 対象メモを集める: 私が直近24時間に編集したページ(主役)と、直近7日に編集したページ(背景)。0件なら「新しいメモなし」と1行報告して終了。
4. 比較相手として、最近のメモに関係する古いページを集める。
5. 次の3つを書く:
   - **CONNECTIONS**: 最近のメモと古いメモの、持ち主がまだ気づいていなさそうな意外なつながりを3つ。具体的に、該当箇所を引用し、元ページにリンクする
   - **PATTERN**: 今週のメモ全体に共通するパターンを1つ。本人がまだ言葉にしていないが、頭が明らかに取り組んでいること
   - **QUESTION**: そのパターンから、今日じっくり考える価値のある問いを1つ。タスクではなく問い
6. 「第二の脳 ブリーフ」の子ページとして「brief YYYY-MM-DD」を作る。
7. 報告は QUESTION とページの URL だけ。コミットはしない。

## 書き方
- 一般論、褒め言葉、メモの要約は書かない。Notion のメモを根拠にする
- 日本語で書く
