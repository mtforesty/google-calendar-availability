# capture

入れる手間を限りなくゼロにするための手順。分類やタグ付けで悩ませない。

1. このリポジトリは public なので、ファイルには保存しない。保存先は Notion の「第二の脳 inbox」ページ(`notion-search` でタイトル検索。無ければ個人ページ直下に作る。チームスペースや共有ページの下には作らない)。
2. その子ページとして作る。タイトルは内容を表す一行、本文の先頭に「captured: YYYY-MM-DD(Asia/Tokyo) / source: <URLや出典>」。
3. 本文は渡された内容をそのまま入れる。要約で置き換えない。
4. 報告は「保存した: <ページURL>」の1行だけ。
